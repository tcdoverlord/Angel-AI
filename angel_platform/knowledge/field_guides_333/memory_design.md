# Memory Design

1. Conversation history records what was said; long-term memory stores only approved durable facts.
2. A memory candidate should include its source, category, timestamp, and approval state.
3. Users must be able to inspect, correct, export, and delete stored memory.
4. Do not save credentials, tokens, private secrets, or every casual statement as permanent memory.
5. Retrieval should be relevance-limited and should show enough provenance for the user to understand why a memory appeared.

## Verification questions

- What evidence was collected?
- What changed, if anything?
- Can the operation be reversed?
- What requires the user's explicit approval?
