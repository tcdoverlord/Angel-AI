# Feedback and Improvement

1. Store ratings and corrections separately from personal memory.
2. Use feedback to adjust prompts, retrieval weighting, and routing rules before considering model training.
3. Keep a distinction between a user preference, a factual correction, and a temporary task instruction.
4. Review feedback for contradictions and stale information before turning it into guidance.
5. Never claim model-weight training occurred when the system only stored feedback or changed prompts.

## Verification questions

- What evidence was collected?
- What changed, if anything?
- Can the operation be reversed?
- What requires the user's explicit approval?
