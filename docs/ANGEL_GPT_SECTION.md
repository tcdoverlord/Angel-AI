# Angel GPT Section 3.0

Specialist GPT profiles sit on top of Angel's main brain.

## Design
Main Angel rules remain authoritative.
A specialist GPT adds focus, domain preferences, and specialist instructions.

## Included GPTs
- Angel
- Python Engineer
- Windows & PowerShell
- Web Developer
- Database & Docker
- Novel Baker
- Moonlit Storyroom
- Math Tutor
- Writing & Literature

## Storage
`data/gpts/gpts.db`
`data/gpts/active_gpt.json`

## User Controls
- Select active GPT from the main window.
- Manage GPTs to create, edit, activate, delete, or refresh profiles.

## Rule
A specialist GPT cannot override Angel's source-truth, capability, safety, or application-authority rules.
