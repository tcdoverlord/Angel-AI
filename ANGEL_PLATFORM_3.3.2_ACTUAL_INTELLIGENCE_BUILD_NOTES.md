# Angel Platform 3.3.2 — Actual Intelligence Expansion

This release preserves the supplied 3.3.2 master baseline and adds an indexed local field-guide corpus.

## Added
- 12 operational field guides covering Windows, Linux, networking, Git/DevOps, Python, local AI, memory, tool execution, Raspberry Pi, observability, security, and recovery.
- Local field-guide indexing in `angel_platform/knowledge/library.py`.
- A manifest describing the corpus and operating principles.

## Design rules
- Evidence-first reporting.
- Explicit approval before impactful operations.
- Reversible changes and rollback guidance.
- Least privilege.
- Separation of personal memory, feedback, and training data.

The field guides are reference material, not a substitute for live system inspection. Angel must verify current machine state before making environment-specific claims.
